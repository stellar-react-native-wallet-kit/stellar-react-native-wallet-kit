# stellar-react-native-wallet-kit

React Native SDK for connecting to Freighter Mobile and interacting with Stellar and Soroban applications through WalletConnect v2.

## Mission

Make Stellar mobile development as simple as wagmi made Ethereum development.

This project provides React Native developers with a clean, modern toolkit for:

- Wallet connection
- Transaction signing
- Soroban contract interaction
- Account management
- WalletConnect session handling

without requiring developers to manage raw XDR, WalletConnect internals, or complex Stellar infrastructure.

## Features

- WalletConnect v2 integration
- Freighter Mobile support
- React hooks API
- Soroban contract helpers
- Transaction signing
- Horizon integration
- TypeScript support
- Testing utilities
- Mock wallet provider
